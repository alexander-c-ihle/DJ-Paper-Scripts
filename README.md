# DJ-Paper-Statistical-Tests
Scripts for histograms/statistical tests, geologic/biologic decision tree and matrix, Monte Carlo analysis, and supporting utilities used in manuscript "Minimal geologic methane emissions in the Denver-Julesburg Basin"

Data used by these scripts is stored with other data for this manuscript at https://doi.org/10.60593/ur.d.33620167 .

MATLAB scripts and example input data for this manuscript's flux calculation technique is available at https://github.com/KatieHall1919/Flux-Calculation
